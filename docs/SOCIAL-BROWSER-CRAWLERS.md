# دریافت مرورگری شبکه‌های اجتماعی

در «منابع و کراولرها → افزودن منبع» نوع پلتفرم را انتخاب و لینک عمومی کانال/صفحه را وارد کنید. دکمهٔ «افزودن و آزمون دریافت» فقط adapter آماده را آزمایش می‌کند؛ AI کراولری برای آن نمی‌سازد. درخواست اجتماعی ادمین نیز بعد از تأیید سوپر ادمین از همین مسیر می‌گذرد. منبع پس از آزمون موفق قابل استفاده است؛ دریافت‌های بعدی طبق فاصلهٔ تنظیم‌شده انجام می‌شوند.

در فرم ادمین و راه‌اندازی رسانه، پس از انتخاب «شبکهٔ اجتماعی»، شبکهٔ موردنظر و سپس آیدی یا لینک کانال/پیج را وارد کنید. آدرس استاندارد پیش‌نمایش می‌شود؛ برای لینک شبکهٔ دیگر، «تغییر به …» همان متن را با شبکهٔ درست تطبیق می‌دهد. ادمین در این فرم وارد حساب اجتماعی نمی‌شود؛ ثبت درخواست همچنان نیازمند تأیید سوپر ادمین و آزمون دریافت است. ADR-0041.

۱۳ کلید: `aparat`, `bale`, `eitaa`, `facebook`, `instagram`, `rubika`, `rubino`, `shad`, `soroush`, `telegram`, `tiktok`, `x`, `youtube`.

پست‌ها و توضیح ویدیو به جریان خبر وارد می‌شوند؛ دانلود ویدیو، انتقال داشبورد مرجع، تحلیل مخاطب و Instagram Stories در این تغییر نیستند. شاد فعلاً به GUID کانال مانند `https://web.shad.ir/#c=...` نیاز دارد. برای یوتیوب لینک کانال `@handle` یا `/channel/UC...` و برای سایر شبکه‌ها لینک پروفایل/کانال، نه یک پست یا لینک دعوت، وارد کنید.

## ورود یک‌باره از پنل سوپر ادمین

از «منابع و کراولرها → ورود شبکه‌های اجتماعی»، شبکه را انتخاب کنید. برای خطای `AUTH_REQUIRED` همان منبع، «راهنمای ورود به …» نیز این پنجره را با شبکهٔ مربوط باز می‌کند. دکمهٔ «ورود به بله روی میزبان» مرورگر را روی رایانه‌ای باز می‌کند که Backend در آن اجراست. شماره/رمز/کد را فقط در صفحهٔ رسمی شبکه وارد کنید. سپس مرورگر را ببندید یا «بستن مرورگر و ادامه» را بزنید و برای همان منبع «آزمون دریافت مجدد» را اجرا کنید.

پنجرهٔ ورود اکنون اندازهٔ واقعی Chrome و مقیاس نمایشگر را دنبال می‌کند و maximized باز می‌شود؛ تب خالی اضافه ساخته نمی‌شود. اگر پنجرهٔ قدیمی با محتوای بریده باز است، آن را ببندید و ورود را دوباره آغاز کنید. در اولین بازشدن بله ممکن است راهنمای نصب وب‌اپ ظاهر شود؛ «متوجه شدم» و سپس «ورود» را انتخاب کنید تا کادر شماره نمایش داده شود.

ورود تا زمان انقضای نشست برای منابع همان شبکه قابل استفاده است. بسته‌شدن پنجره به معنی ورود موفق نیست؛ آزمون دریافت، اعتبار نشست و استخراج را می‌سنجد. اگر از دستگاه دیگری به پنل وصل هستید، ورود باید در محیط گرافیکی میزبان انجام شود. این قابلیت اطلاعات حساب ادمین رسانه را دریافت نمی‌کند.

خطای واقعی بله `ble.ir/gizmiztel` در 2026-11-04، `AUTH_REQUIRED` با صفر پست کشف/درج بود؛ ورود واقعی و نتیجهٔ دریافت پس از آن هنوز تأیید نشده‌اند. ADR-0042.

### تنظیم کنترل ورود روی میزبان

بازکردن مرورگر از پنل در توسعهٔ Windows یا محیط دارای DISPLAY/WAYLAND فعال و در production پیش‌فرض خاموش است. برای فعال‌سازی صریح روی میزبان گرافیکیِ موردنظر:

```dotenv
SOCIAL_BROWSER_INTERACTIVE_LOGIN=true
```

با `false` می‌توان کنترل بازکردن را غیرفعال کرد؛ راهنمای خط فرمان همچنان در پنل در دسترس است. CLI را از پوشهٔ `back` اجرا کنید؛ مانند API، تنظیمات `.env.local` را می‌خواند.

## آماده‌سازی مرورگر و پروفایل

وابستگی `puppeteer-core` با نصب Backend نصب می‌شود؛ خود مرورگر باید روی میزبان موجود باشد. Chrome ویندوز، Edge ویندوز و مسیرهای رایج Linux شناسایی می‌شوند؛ برای مسیر دیگر:

```dotenv
SOCIAL_BROWSER_EXECUTABLE=C:/Program Files/Google/Chrome/Application/chrome.exe
# مسیر مطلق، مشترک بین API و Worker همان استقرار؛ بیرون از پوشهٔ عمومی:
SOCIAL_BROWSER_PROFILE_DIR=D:/private-media-state/social-browser
```

پروفایل‌ها cookie و نشست حساب را نگه می‌دارند. دسترسی پوشه را به کاربر سرویس محدود کنید و در production از volume رمزگذاری‌شده استفاده کنید. هر پلتفرم حساب/پروفایل مستقل دارد؛ برای چند Worker، یک پروفایل را هم‌زمان اجرا نکنید. وضعیت `SOCIAL_PROFILE_BUSY` یعنی پروفایل در حال استفاده است.

از پوشهٔ `back`، فقط برای شبکهٔ نیازمند ورود:

```powershell
npm run social:login -- telegram
```

ورود را در پنجرهٔ بازشده کامل کنید و همهٔ پنجره‌های همان پروفایل را ببندید. این فرمان cookie/رمز را چاپ نمی‌کند و بازشدن مرورگر، ورود معتبر را تضمین نمی‌کند. برای سایر پلتفرم‌ها کلید مربوط را جایگزین کنید. دستور ورود به محیط گرافیکی میزبان نیاز دارد.

آزمون مستقل بدون ساخت منبع، فعال‌سازی یا نوشتن در Inbox:

```powershell
npm run social:check -- aparat https://www.aparat.com/aparat
```

خروجی فقط مرحله و شمار استخراج/شکست/تاریخ/تصویر است. خطای `AUTH_REQUIRED` به نشست نیاز دارد؛ `SOCIAL_BROWSER_NOT_INSTALLED` به مسیر مرورگر؛ `SOCIAL_CRAWL_TIMEOUT` به بررسی شبکه/نشست؛ و استخراج جزئی به بررسی گزارش اجرا. ورود، CAPTCHA و تغییر DOM هر شبکه باید روی همان شبکه بررسی شوند؛ خطا موفقیت اعلام نمی‌شود و نسخهٔ ناموفق جای نسخهٔ فعال نمی‌نشیند.

## وضعیت تأیید

در 2026-11-03 بارگذاری مستقل هر ۱۳ adapter و جریان ذخیره‌سازی/توزیع/مجوز/تکرار/لغو آزموده شد. آپارات زنده ۶۰ ویدیو/شورت با تاریخ و تصویر و صفر شکست استخراج داد. ۱۲ شبکهٔ دیگر هنوز آزمون زندهٔ دارای نشست معتبر ندارند. آزمون‌های fixture فقط زیر `back/tests` هستند؛ runtime محصول خروجی ساختگی ندارد. تصمیم و مرز امنیتی در ADR-0040 ثبت شده‌اند.
