# ADR-0042 — ورود مرورگری شبکه‌ها از پنل سوپر ادمین

تاریخ: ۱۴۰۵/۰۸/۱۳ (2026-11-04) — پذیرفته‌شده

## شاهد مسئله

بررسی کپی تشخیصی دیتابیس محلی نشان داد آزمون اولیهٔ منبع بله `https://ble.ir/gizmiztel` در 2026-11-04 ساعت ۰۹:۵۷:۴۴ تهران با `AUTH_REQUIRED` پایان یافته است. شمار کشف/درج صفر و منبع غیرفعال/failed است. گزارش اجرا صریحاً نشست واردنشده یا منقضی را نشان می‌دهد؛ موفقیت استخراج پس از ورود هنوز بررسی نشده است.

## تصمیم

در پنل سوپر ادمینِ منابع، بخش «ورود شبکه‌های اجتماعی» و میان‌بر کنار خطای احراز هویت اضافه می‌شود. شبکه انتخاب می‌شود، مرورگر روی **میزبان Backend** با پروفایل مشترک همان adapter باز می‌شود و سوپر ادمین ورود را فقط در صفحهٔ رسمی شبکه انجام می‌دهد. این قابلیت ورود به حساب ادمین رسانه یا دریافت credential در داشبورد نیست. میزبان بدون محیط گرافیکی روش خودکار ورود ندارد؛ راهنمای CLI و نیاز به محیط گرافیکی نمایش داده می‌شود.

بستن پنجره فقط چرخهٔ مرورگر را خاتمه می‌دهد. وضعیت‌ها idle/opening/open/closing/closed/failed هستند و هیچ‌کدام ادعای authentication نیستند. پس از بستن، سوپر ادمین «آزمون دریافت مجدد» همان منبع را انتخاب می‌کند؛ gate موجود دربارهٔ فعال‌سازی و دسترسی درخواست‌های تأییدشده تصمیم می‌گیرد. از درخواست اجتماعی ناموفق نیز لینک بررسی نشست و گزارش موجود است.

## قرارداد و کنترل‌ها

- GET `/api/v1/platform/social-browser-sessions` فقط برای Platform Admin است و وضعیت پنجره‌ها/قابلیت میزبان را می‌دهد؛ cookie، شماره، credential، DevTools یا مسیر پروفایل ندارد.
- POST همان مسیر به‌علاوهٔ `/:platform/open` و `/:platform/close` فقط JSON خالی، platform ثبت‌شده، نشست سوپر ادمین و Origin هم‌مبدأ/صریحاً مجاز را می‌پذیرد. آدرس مقصد از تنظیم ثابت همان شبکه می‌آید؛ payload دلخواه URL/command پذیرفته نیست. درخواست باز/بستن audit می‌شود.
- در توسعهٔ Windows/محیط گرافیکی، کنترل ورود فعال است؛ در production پیش‌فرض خاموش و فعال‌سازی صریح با `SOCIAL_BROWSER_INTERACTIVE_LOGIN=true` است. بدون GUI باید از محیط گرافیکی میزبان اقدام شود؛ بازشدن پنجره روی دستگاه مراجعه‌کننده وعده داده نمی‌شود.
- پروفایل، پراکسی محدود، DNS/IP pinning، پاک‌سازی مرورگر و قفل همان runtime دریافت استفاده می‌شوند. ورود حداکثر ۲۰ دقیقه باز می‌ماند؛ شروع تکراری همان پنجره را گزارش می‌کند. scheduler همان فرایند، پروفایل مشغول را رد می‌کند تا ورود با دریافت محلی تداخل نکند؛ قفل Chrome همچنان محافظ بین فرایندهاست.
- فرمان‌های `social:login` و `social:check` اکنون `.env.local` همان Backend را می‌خوانند تا مسیر پروفایل/مرورگر با API یکسان بماند. حفاظت volume پروفایل‌های production طبق ADR-0040 همچنان الزامی است.

## ارزیابی

۱۱۱ تست Backend، typecheck Backend/contracts/worker، ۱۲ تست Front، lint و build واقعی Next.js موفق‌اند. آزمون تازه authorization، Origin، payload ثابت، audit، شروع تکراری، بستن، عدم افشای خطا و عدم ادعای ورود از بسته‌شدن پنجره و توقف زمان‌بندی محلی هنگام استفادهٔ پروفایل را پوشش می‌دهد.

کامپوننت واقعی پنل در محیط آزمون مستقل، با API و PGlite حافظه‌ای و runner مرورگرِ آزمایشی، برای باز/بستن، راهنمای CLI و صف آزمون منبع بازبینی شد؛ عرض ۳۹۰ بدون سرریز بود. این تست جای ورود زنده به حساب بله را نمی‌گیرد. هیچ login واقعی، فعال‌سازی منبع بله یا ورود پست آن به Inbox در این بررسی انجام نشد. پاک‌سازی کپی تشخیصی موقت دیتابیس با پیام «blocked by policy» توسط ابزار اجرا رد شد؛ کپی در Temp باقی است، بیرون از Git و runtime. دیتابیس اصلی برای تشخیص بازنویسی نشد.

## اصلاح اندازهٔ پنجرهٔ ورود — 2026-11-04

گزارش پنجرهٔ ناقص بله به viewport ثابت ۱۴۴۰×۱۰۰۰ مربوط بود: در نمایشگر دارای DPI برابر ۱۲۵٪، ارتفاع شبیه‌سازی‌شده از بخش فیزیکی قابل‌دیدن بزرگ‌تر بود و دکمهٔ ورود پایین صفحه قرار می‌گرفت. برای ورود دستی `defaultViewport: null` و `--start-maximized` اعمال شد؛ اندازهٔ داخلی از پنجرهٔ واقعی می‌آید. تب آغازین Chrome استفاده می‌شود و تب about:blank اضافی ساخته نمی‌شود. دریافت headless همچنان viewport پایدار ۱۴۴۰×۱۰۰۰ دارد و پروفایل/پراکسی/کنترل شبکه مشترک حفظ شدند.

بررسی زندهٔ مستقل صفحهٔ عمومی بله در Chrome با مقیاس ۱۲۵٪ و پنجرهٔ ۱۰۰۰×۷۰۰، viewport برابر ۹۸۴×۶۰۶ و دکمهٔ ورود در y=538.8 تا 590.8 نشان داد؛ پس از تأیید راهنمای نصب و انتخاب ورود، کادر شماره در y=244.6 تا 268.6 داخل صفحه بود. شماره یا کد وارد نشد و حساب واقعی احراز نشد. آزمون رگرسیون، نداشتن emulation در ورود، استفاده از تب آغازین، ثبات viewport worker و یکسان‌بودن پروفایل/محافظ شبکه را پوشش می‌دهد.
