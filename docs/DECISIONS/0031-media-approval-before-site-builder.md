# ADR-0031 — تأیید رسانه پیش از سایت‌ساز

وضعیت: پذیرفته‌شده و پیاده‌شده — 2026-10-28

## تصمیم

- ساخت رکورد رسانه و ذخیرهٔ فرم/نیازهای طراحی در wizard فقط پیش‌نویس است و مجوز اجرای سایت‌ساز یا انتشار نیست.
- تکمیل نهایی فرم در همان تراکنش یک درخواست `pending` در `media_creation_request` ثبت می‌کند؛ ذخیرهٔ دوباره درخواست/تأیید قبلی را بازنشانی نمی‌کند.
- درخواست‌ها در منوی مستقل «درخواست‌های رسانه» و مسیر `/platform/media-requests` نمایش داده می‌شوند. سوپر ادمین اطلاعات رسانه، متقاضی، سایت، منابع و نام سردبیرها را می‌بیند و تأیید یا با دلیل رد می‌کند.
- تنها سوپر ادمین می‌تواند درخواست را بررسی کند. نسخه، تصمیم‌گیر، یادداشت و زمان تصمیم ثبت و ممیزی می‌شوند؛ تصمیم هم‌زمان یا مجدد رد می‌شود.
- اصل deny-by-default برقرار است: بدون درخواست تأییدشده، فعال‌سازی و پیش‌نمایش سایت، سرو عمومی/نقشهٔ سایت، ثبت انتشار و اجرای worker انتشار مسدودند. پس از ارسال نهایی، ویرایش سایت نیز تا تأیید مسدود است. آپلود/پیش‌نمایش لوگو و ذخیرهٔ مشخصات در wizard مجاز باقی می‌مانند.
- بررسی منابع تا تأیید رسانه متوقف است و در فهرست منابع، لینک بررسی رسانه نمایش داده می‌شود؛ تأیید رسانه به معنی اعطای خودکار دسترسی منابع نیست.
- ادمین وضعیت انتظار/تأیید/رد و یادداشت سوپر ادمین را در داشبورد می‌بیند. API وضعیت فقط رسانهٔ فعال همین نشست را برمی‌گرداند.
- رسانه‌های قبلی با فرم تکمیل‌شده به حالت pending مهاجرت می‌کنند؛ سایت یا رسانهٔ قدیمی خودکار تأیید نمی‌شود.
- API در شروع نیز فرم‌های تکمیل‌شدهٔ فاقد درخواست را به‌صورت idempotent ثبت می‌کند؛ تصمیم‌های موجود هرگز بازنشانی نمی‌شوند.

## محدودیت فعلی

این تغییر مجوز شروع سایت‌ساز را اعمال می‌کند. تولید طراحی اختصاصی سایت با هوش مصنوعی و صف ساخت/پیشرفت آن همچنان کار بعدی است؛ تأیید رسانه نباید در UI با «سایت ساخته شد» یکسان نمایش داده شود. سایت‌ساز فعلی تنظیمات و renderer داخلی را دارد.
