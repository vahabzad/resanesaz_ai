# ADR-0013 — نسخه‌بندی و مرجع خبر در تحریریه

تاریخ: 2026-10-06 — وضعیت: پذیرفته‌شده

با درخواست شروع فاز بعد، اولین مسیر تحریریه دستی پیاده شد. Story، سرویس، سیاست، نسخه و تصمیم انسانی متعلق به Media هستند. شناسهٔ رسانه از نشست و عضویت استخراج می‌شود و ورودی مشتری نمی‌تواند scope را تعیین کند؛ ادمین Platform به‌تنهایی مجوز تحریریه ندارد.

- ورود اولیه فقط از Inbox همان رسانه و خبر غیرقرنطینه دارای متن کافی است؛ سرویس و سیاست باید قبلاً توسط مدیر رسانه ثبت شوند.
- Article Version و Editorial Policy از API ویرایش نمی‌شوند؛ هر تغییر رکورد تازه‌ای می‌سازد. هر نسخه شناسهٔ دقیق سیاست و عامل را نگه می‌دارد.
- شمارندهٔ revision با مقایسه و افزایش اتمیک مانع از دست‌رفتن ویرایش هم‌زمان می‌شود. تصمیم انسانی فقط برای آخرین نسخهٔ draft ثبت می‌شود؛ نسخهٔ جدید، تأیید قبلی را به ارث نمی‌برد.
- Story Source، snapshot متن/عنوان/تصویر/URL/نام منبع/provenance را نگه می‌دارد. حذف Raw فقط اشاره‌گر آن را null می‌کند و سابقهٔ تحریریه را حذف نمی‌کند؛ این تصمیم مکمل ADR-0012 است.
- ذخیرهٔ نسخه، تصمیم و audit در یک transaction انجام می‌شود. نمایش متن، HTML خام را اجرا نمی‌کند.

این مرحله بازنویسی هوشمند، انتشار، سرویس سلسله‌مراتبی، اتصال/قطع چند منبع و سه rendition مستقل را کامل نمی‌کند. مدل Story Source برای چند منبع آماده است، ولی مسیر فعلی فقط یک منبع اولیه دارد. مقایسهٔ نسخه‌ها فعلاً کنار هم است، نه diff خطی. فهرست حداکثر ۲۰۰ خبر اخیر را می‌خواند.
