# ADR-0001: هستهٔ مرکزی و اتصال adapter-based

وضعیت: پذیرفته‌شده در سطح جهت معماری

تاریخ: 2026-09-27

## زمینه

سه پروژهٔ موجود هر کدام یک توانایی مفید دارند، اما مدل هویت، ذخیره‌سازی، workflow و UI مستقل خود را دارند. محصول جدید نیازمند چند رسانه، چند سایت، چند بات و کنترل انتشار یکپارچه است.

## تصمیم

یک Control Plane جدید مالک مدل دامنه، مجوزها، workflow و Audit Log خواهد بود. قابلیت‌های سه پروژه از طریق adapter و قرارداد نسخه‌دار مصرف می‌شوند. UIهای موجود و مدل ذخیره‌سازی فایل‌محور آن‌ها مبنای محصول جدید نخواهند بود.

## پیامدها

- فرانت فقط با API هسته تعامل می‌کند.
- تعویض یا بازنویسی هر بازو بدون تغییر اساسی UI ممکن می‌شود.
- کار اولیهٔ بیشتری برای قرارداد و orchestration لازم است.
- منطق قابل استفادهٔ پروژه‌های مرجع حفظ می‌شود ولی coupling مستقیم کاهش می‌یابد.
