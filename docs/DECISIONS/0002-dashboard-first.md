# ADR-0002: تثبیت داشبورد پیش از گسترش محصول

وضعیت: پذیرفته‌شده

تاریخ: 2026-09-27

## زمینه

کیفیت UI/UX و حس خبری مدرن اولویت اصلی مالک محصول است. توسعهٔ هم‌زمان همهٔ صفحات پیش از تثبیت زبان طراحی، احتمال بازکاری گسترده دارد.

## تصمیم

ابتدا dashboard shell و صفحهٔ اصلی با دادهٔ Mock قراردادی ساخته می‌شود. پس از تأیید جهت بصری و تجربه، توسعه به vertical sliceهای فرانت و بک‌اند گسترش می‌یابد.

## پیامدها

- بازخورد طراحی زود دریافت می‌شود.
- Mockها باید با مدل دامنه هم‌راستا باشند تا فرانت دورریختنی نشود.
- تا پیش از تأیید، صفحات فرعی و بک‌اند جدید ساخته نمی‌شوند.

## نتیجهٔ Gate

Dashboard v1 در 2026-09-27 به‌طور کامل توسط مالک محصول تأیید شد. محدودیت توقف توسعهٔ صفحات فرعی و بک‌اند برداشته شد و زبان طراحی فعلی مبنای ادامهٔ محصول است.
