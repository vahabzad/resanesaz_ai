# ADR-0028 — هویت بصری و تأیید لوگو پیش از ذخیره

وضعیت: پذیرفته‌شده و پیاده‌سازی‌شده — 2026-10-28

## تصمیم

- آپلود/جایگزینی لوگو داخل بخش هویت بصری فرم سایت انجام می‌شود و تصویر در اندازهٔ اصلی و کنار نام رسانه بلافاصله پیش‌نمایش دارد. PNG/JPEG/WebP حداکثر یک مگابایت با اعتبارسنجی باینری Backend پذیرفته می‌شوند.
- «طراحی لوگوی تازه» توضیح سبک می‌گیرد. API نسخه‌دار `/api/v1/media/logo-preview` پیش از ساخت Media نیز فقط برای ادمین احرازشده در دسترس است؛ از همان factory و نشست مدل موجود Backend استفاده می‌کند. هر درخواست thread مستقل با shell، شبکه، ابزار و MCP غیرفعال و مهلت ۱۸۰ ثانیه دارد. سه طراحی هم‌زمان در هر process و یک طراحی برای هر ادمین مجاز است؛ فاصلهٔ درخواست هر ادمین حداقل پنج ثانیه است.
- لوگوی تازه یک نشان برداری کنار نام رسانه است. مدل فقط JSON شامل رنگ و pathهای محدود برمی‌گرداند؛ schema، تعداد/طول مسیرها، رنگ و ضخامت را کنترل می‌کند. SVG تنها با renderer ثابت محصول ساخته می‌شود؛ متن SVG/HTML، URL یا کد تولیدی مدل اجرا نمی‌شود.
- طرح بدون تأیید صریح قابل ثبت نیست. نام، توضیح، رنگ‌ها و مشخصات هویت بصری هنگام تولید snapshot می‌شوند؛ UI و Backend پس از تغییر آن‌ها تأیید طرح قبلی را معتبر نمی‌دانند. تولید طرح هیچ Media یا Site را ایجاد یا عمومی نمی‌کند.
- «هویت بصری مشخص دارم» توضیح شخصیت برند، قواعد رنگ، تایپوگرافی، سبک تصویر/نماد و چیدمان را اجباری می‌کند؛ محدودیت‌ها و لینک راهنمای برند اختیاری‌اند. لینک فقط مرجع ذخیره‌شده است و fetch نمی‌شود. جزئیات در `designBrief.design.identityDetails` خصوصی ذخیره و هنگام تولید لوگو به مدل داده می‌شوند.
- لوگوی نهایی در `spec.logo` و لوگوی Media همان scope ذخیره می‌شود. به‌روزرسانی لوگو و سایت و audit در تراکنش واحد انجام می‌شود؛ دادهٔ آپلودی در brief دوباره ذخیره نمی‌شود. خروجی عمومی فقط تصویر نهایی را می‌گیرد، نه توضیح/پرامپت/قواعد برند. `liveSpec` مستقل می‌ماند و لوگوی عمومی فقط با فعال‌سازی نسخهٔ طراحی تغییر می‌کند.
- timeout پراکسی Next به ۲۰۰ ثانیه تنظیم شد تا پاسخ مدل در مهلت پیش‌نمایش به مرورگر برسد. تولید تصویر raster یا سرویس ثالث جدید در این تغییر اضافه نشده است.

## بررسی

آزمون API مجوز قبل از Media، محدودیت تکرار، schema خروجی، تأیید و ابطال آن، آپلود معتبر/نامعتبر، مرز Media، خصوصی‌ماندن brief و استقلال لوگوی live را پوشش می‌دهد. یک inference واقعی نشان برداری تولید کرد. در صفحهٔ مستقل آزمایش، آپلود و نمایش فوری، حالت‌های شرطی، تأیید و باطل‌شدن تأیید پس از ویرایش در مرورگر بررسی شدند؛ دادهٔ آزمایش به Mediaهای محصول اضافه نشد.
