# ADR-0032 — داشبورد وضعیت ادمین و مرز فاز اول

وضعیت: پذیرفته‌شده و پیاده‌شده — 2026-10-31

به‌روزرسانی 2026-11-02: طبق ADR-0035، منوی «سردبیرهای من» و مدیریت/پایش سردبیرها به درخواست مالک محصول به فاز جاری اضافه شدند؛ محدودیت این سند دربارهٔ آن بخش اصلاح شده است.

## تصمیم محصولی

پس از ارسال فرم، اولین محتوای داشبورد ادمین وضعیت درخواست و یادداشت سوپر ادمین است. منو در فاز اول فقط پنج مورد دارد:

- داشبورد (وضعیت)
- اخبار ورودی؛ پس از تأیید رسانه و دسترسی به حداقل یک منبع فعال می‌شود.
- منابع من؛ فهرست درخواست‌ها/دسترسی‌ها و افزودن درخواست منبع تازه با انتخاب دسته‌های کاتالوگ.
- مدیریت سایت؛ صرفاً وضعیت واقعی سایت و لینک مشاهدهٔ سایت آماده.
- بات‌های شبکه‌های اجتماعی؛ صفحهٔ روشن «فاز دوم» بدون دریافت credential یا تنظیم عملیاتی.

ویرایش طراحی و تنظیمات سایت، میز تحریریه، انتشار و سایر منوهای مدیریتی در این نمای ادمین ارائه نمی‌شوند؛ پیاده‌سازی‌های موجود Backend حذف نمی‌شوند. نمای مدیریتی سراسری سوپر ادمین مستقل می‌ماند.

## داده و دسترسی

- `/api/v1/media/overview` فقط برای رسانهٔ فعال نشست است و وضعیت درخواست، فهرست منابع، اجازهٔ اخبار و خلاصهٔ سایت را از دادهٔ پایدار برمی‌گرداند. تنظیمات خصوصی سایت و لوگو در این پاسخ نیستند.
- تأیید رسانه به‌تنهایی دسترسی اخبار را باز نمی‌کند. اشتراک منبع باید فعال، منبع قابل ارائه به رسانه و بایگانی‌نشده باشد. Inbox API نیز خبرها و شمارها را به همین منابع محدود می‌کند؛ دسترسی صفر برای ادمین ۴۰۳ است.
- پیش‌نویس سایت به معنی ساخته‌شدن سایت نیست. با نبود صف ساخت، وضعیت «ساخت هنوز آغاز نشده» نمایش داده می‌شود؛ وضعیت «در حال ساخت» ساختگی ممنوع است. لینک فقط برای سایت live دارای نسخهٔ منتشرشده و رسانهٔ تأییدشده نمایش داده می‌شود.
- فرم افزودن منبع از API قبلی استفاده می‌کند؛ همان قواعد تکراری‌نبودن و بررسی سوپر ادمین حفظ می‌شوند. در انتظار تأیید رسانه نیز درخواست تازه قابل ثبت است و بررسی آن متوقف می‌ماند.
- انتخاب رسانه، خروج از حساب و بنر impersonation حفظ می‌شوند. loading/error/refresh واقعی وجود دارند.
