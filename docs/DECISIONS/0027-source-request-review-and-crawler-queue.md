# ADR-0027 — رسیدگی به درخواست منبع و صف ساخت کراولر

وضعیت: پذیرفته‌شده بر اساس تصمیم مالک محصول — ۱۴۰۵/۰۸/۰۵

## تصمیم

- درخواست‌های افزودن منبع در فضای سوپر ادمین و زیر بخش «منابع و کراولرها» با پیوند مستقل «درخواست‌های منابع» بررسی می‌شوند؛ صفحهٔ ادمین‌ها فقط برای مدیریت حساب ادمین است.
- هر درخواست یکی از سه تصمیم را می‌گیرد: رد، اعطای دسترسی به Source دارای crawler آماده، یا تأیید و صف ساخت crawler.
- درخواست منبع با لینک یکسان، حتی اگر درخواست فعال یا دسترسی دیگری برای همان لینک وجود داشته باشد، رد نمی‌شود؛ هر درخواست جداگانه در صف سوپر ادمین بررسی می‌شود.
- ساخت از درخواست به همان Source و CrawlRun متصل است. پس از موفقیت build، subscription رسانه با تنظیم همه/دسته‌های انتخابی ایجاد یا به‌روز می‌شود؛ شکست build درخواست را crawler_failed می‌کند و retry آن ممکن است.
- تأیید آماده فقط برای crawler فعال، Source غیرآرشیوشده و delivery-enabled مجاز است.
- درخواست شبکهٔ اجتماعی نیز در همین فهرست می‌آید؛ ساخت آن از adapter وب فعلی استفاده می‌کند و باید در مرحله‌های بعدی براساس رفتار واقعی شبکه ارزیابی شود.

## پیامدها

- وضعیت درخواست‌ها شامل pending، rejected، crawler_queued، crawler_failed و access_granted است.
- انتخاب دسته‌های وب‌سایت در subscription هم ذخیره می‌شود و پس از build به رسانه وصل می‌ماند.
- هر تصمیم و نتیجهٔ خودکار build در audit ثبت می‌شود.
