# ADR-0040 — کراولرهای ثابت مرورگری شبکه‌های اجتماعی

تاریخ: ۱۴۰۵/۰۸/۱۲ (2026-11-03) — پذیرفته‌شده

## تصمیم

برای شبکه‌های اجتماعی recipe یا کد با AI تولید نمی‌شود. ۱۳ adapter ثابت با کلیدهای aparat، bale، eitaa، facebook، instagram، rubika، rubino، shad، soroush، telegram، tiktok، x و youtube در Backend قرار دارند. منطق استخراج مرورگری و parserهای موردنیاز از `VAV_backend/domain/crawl/platforms` به `back/src/social/engine` منتقل و وابستگی‌های پنل، ORM، registry و configuration برنامهٔ مرجع حذف شدند. این پوشهٔ مستقل در runtime هیچ import، HTTP call یا نیاز استقراری به مخزن مرجع ندارد. README مرجع دربارهٔ login-only بودن تیک‌تاک قدیمی است؛ در snapshot کد، کراولر مرورگری وجود دارد.

خواندن پاسخ‌های شبکه یا فراخوانی read endpoint توسط JavaScript داخل نشست همان مرورگر، بخشی از adapter مرورگری است. مسیر client/API مستقل بدون مرورگر منتقل نشده است. شاد برای رمزگشایی پاسخ همان نشست، helper رمزنگاری لازم دارد؛ credential یا پاسخ خام آن وارد Raw Article نمی‌شود.

## یکپارچه‌سازی

- `adapterKey` منبع یکی از web، rss یا کلید پلتفرم است؛ ستون متنی موجود migration نمی‌خواهد.
- مسیر موجود create/build برای منبع اجتماعی فقط **آزمون اتصال و استخراج adapter ثابت** را صف می‌کند. فعال‌سازی پس از نمونهٔ واقعی دارای متن و بدون شکست استخراج است؛ نمونه‌های آزمون به Inbox نمی‌روند. دیباگ با Codex مختص web باقی می‌ماند.
- crawl زمان‌بندی‌شده/دستی، توقف، گزارش اجرا و دسترسی سوپر ادمین همان سازوکار موجود را مصرف می‌کنند. یک دریافت Platform-scoped به Inbox مشترکان مجاز توزیع می‌شود.
- شناسهٔ بومی پست در externalId و provenance ثبت می‌شود؛ hash اجتماعی از adapter × externalId در scope منبع ساخته می‌شود و تغییر عنوان همان پست، خبر تکراری نمی‌سازد.
- خروجی فقط متن، تاریخ، تصویر عمومی، لینک قابل اعتبارسنجی و شناسه است. پست بدون متن به خبر ساختگی تبدیل نمی‌شود. آمار مخاطب، stories و فایل‌های ویدیویی وارد دامنهٔ خبر نشده‌اند. نبود آمار اختیاری آپارات خبر دارای متن/تاریخ را نامعتبر نمی‌کند؛ ویدیوهای کانال دیگر صریحاً کنار گذاشته می‌شوند.
- لینک شاد GUID دارد و hash حاوی `c=` بخشی از هویت منبع است. آدرس اجتماعی ناشناخته یا ناسازگار با پلتفرم رد می‌شود. منابع قدیمی به‌صورت خودکار بازنویسی نمی‌شوند.

## مرز مرورگر و نشست

Chrome/Chromium/Edge فقط روی میزبان Backend/Worker اجرا می‌شود. پروفایل هر پلتفرم مستقل و خصوصی است؛ چرخهٔ دریافت headless است. CLI ورود، تنها مسیر بازکردن پنجرهٔ قابل مشاهده است. اتصال به مرورگر شخصی یا DevTools فرایند دیگر حذف شده است. هم‌زمانی درون فرایند به‌ازای پلتفرم رد می‌شود؛ قفل Chrome نیز پروفایل مشترک بین فرایندها را محافظت می‌کند.

ترافیک مرورگر از پراکسی محلی CONNECT می‌گذرد: فقط دامنه‌های allowlist همان پلتفرم و TLS/443، resolve عمومی و اتصال به IP اعتبارسنجی‌شده، بدون fallback مستقیم. QUIC، bypass لوپ‌بک و WebRTC بدون پراکسی غیرفعال‌اند. سقف هر دریافت ۵ دقیقه، ۱۲۰۰ تونل، ۱۲۸MiB ترافیک و ۵۰۰ پست است. خاتمه/لغو، مرورگر و تونل‌ها را می‌بندد. پروفایل‌ها secret هستند و باید از Git، وب، log و backup عمومی خارج باشند؛ برای استقرار production باید روی volume رمزگذاری‌شده با دسترسی سرویس نگهداری شوند. این تغییر vault عمومی credentialهای انتشار را پیاده نمی‌کند.

## شواهد و محدودیت

۱۰۳ آزمون Backend، typecheck Backend/contracts/worker، ۱۲ آزمون Front، lint و build واقعی Next.js موفق‌اند. فرم واقعی افزودن منبع جداگانه در عرض ۳۹۰ بدون سرریز بازبینی شد. آزمون زندهٔ مستقل آپارات ۶۰ مورد دارای تاریخ و تصویر، صفر شکست استخراج و حذف دو مورد کانال دیگر داشت؛ هیچ Source واقعی ساخته یا نمونه‌ای وارد Inbox نشد. بارگذاری مستقل همهٔ adapterها و parserهای منتخب آزموده شده؛ ورود و استخراج زندهٔ ۱۲ پلتفرم دیگر تأیید نشده و به نشست، شبکه و سازگاری وب‌کلاینت جاری وابسته است. این ADR ادعای آماده‌بودن عملیاتی همگانی ندارد.
