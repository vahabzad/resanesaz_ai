# ADR-0024 — کنترل حساب ادمین و ورود موقت سوپر ادمین

وضعیت: پذیرفته‌شده و پیاده‌سازی‌شده — ۱۴۰۵/۰۸/۰۵

## تصمیم

- سوپر ادمین می‌تواند نام و ایمیل ادمین را ویرایش کند و در صورت نیاز گذرواژهٔ او را بازنشانی کند. بازنشانی گذرواژه نشست‌های فعال ادمین را باطل می‌کند؛ تغییر ایمیل نشان تأیید ایمیل را پاک می‌کند.
- حذف ادمین فقط وقتی مجاز است که عضو هیچ رسانه‌ای نباشد. این قید مانع باقی‌ماندن رسانهٔ بدون عضو می‌شود؛ حذف موفق حساب، نشست‌هایش را نیز از بین می‌برد.
- ورود به حساب ادمین با قابلیت impersonation پلاگین Better Auth انجام می‌شود. نشست اصلی سوپر ادمین حفظ می‌شود، نشست موقت یک ساعت اعتبار دارد، و بازگشت فقط به نشست اصلی ذخیره‌شده ممکن است.
- آغاز و پایان ورود موقت، ویرایش و حذف در Audit Event ثبت می‌شوند. کاربر هنگام ورود موقت نشان واضح وضعیت و دکمهٔ بازگشت می‌بیند؛ اگر هنوز رسانه‌ای نداشته باشد، مستقیم به فرم ساخت رسانه می‌رود و همان امکان بازگشت را دارد.
- تنها حساب‌های media_admin هدف impersonation هستند. مجوزهای Better Auth برای نقش فنی admin (سوپر ادمین محصول) به impersonate محدود شده‌اند تا endpointهای داخلی ساخت/حذف/تغییر نقش آن پلاگین راه جایگزین مدیریت ادمین‌ها نسازند؛ دسترسی APIهای محصول نیز براساس platform_admin و نشست جاری بررسی می‌شود.

## پیامدها

- فیلدهای Better Auth برای نقش ادمین و منشأ نشست impersonation افزوده شدند. مهاجرت، حساب‌های موجود در platform_admin را به نقش فنی Better Auth admin ارتقا می‌دهد؛ حساب‌های ادمین نقش پیش‌فرض عادی می‌گیرند.
- انتقال یا حذف عضویت رسانه پیش از حذف ادمینی که هنوز رسانه دارد، باید در جریان مدیریت رسانه پیاده‌سازی شود.
