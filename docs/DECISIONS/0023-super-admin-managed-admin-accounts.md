# ADR-0023 — ساخت حساب ادمین توسط سوپر ادمین

وضعیت: پذیرفته‌شده و پیاده‌سازی‌شده — ۱۴۰۵/۰۸/۰۵

## زمینه

خط مبنای تازهٔ محصول فقط یک سوپر ادمین دارد. ادمین (سردبیر) می‌تواند پیش از ساخت رسانه در سامانه ثبت شود و فهرست مستقلی داشته باشد. ثبت‌نام عمومی نباید امکان ساخت حساب یا ارتقای نقش را فراهم کند.

## تصمیم

- فضای Platform یک صفحهٔ «ادمین‌ها» دارد؛ سوپر ادمین می‌تواند ادمین بسازد و فهرست ادمین‌ها، زمان ایجاد و تعداد رسانه‌های هرکدام را ببیند.
- ادمین یک هویت دامنه‌ای مستقل در `media_admin` دارد و لازم نیست هنگام ایجاد به رسانه‌ای متصل باشد.
- ساخت حساب از API محافظت‌شدهٔ Platform انجام می‌شود. سوپر ادمین گذرواژهٔ اولیه را تعیین می‌کند؛ سرور فقط hash را ذخیره می‌کند و گذرواژه را در پاسخ یا log ثبت نمی‌کند.
- ثبت‌نام عمومی Better Auth غیرفعال است؛ bootstrap محدود نصب اولیه از مسیر CLI جداگانه باقی می‌ماند.
- درخواست ساخت همراه با audit event ثبت می‌شود. حساب جدید جلسهٔ ورود دریافت نمی‌کند و اطلاعات گذرواژه باید جداگانه و امن به صاحب حساب تحویل شود.
- پیوند «ورود به فضای رسانه» از navigation سوپر ادمین حذف شده است؛ دسترسی مستقیم به آدرس صفحهٔ ادمین و کنترل مجوز همچنان برقرار است.

## پیامدها

- migration افزایشی `media_admin` را ایجاد می‌کند و دادهٔ فعلی سوپر ادمین را تغییر نمی‌دهد.
- گام بعدی محصول، درخواست/تصمیم دسترسی منابع و سپس نگاشت دسته‌بندی خام به داخلی است.
