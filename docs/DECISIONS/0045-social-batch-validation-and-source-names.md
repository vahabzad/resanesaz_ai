# ADR-0045: دریافت محدود اجتماعی و هویت منبع

تاریخ: 2026-11-07

تست واقعی @jarian_com نشان داد خروجی قابل استفاده به دلیل پیام بدون متن و پایان سقف ۲۰ پیمایش رد می‌شد. نام پروفایل نیز دریافت، ولی در منبع ذخیره نمی‌شد؛ نام خودکار دامنه در UI باقی می‌ماند.

پیام فاقد متن/عنوان/کپشن/توضیح خبر نیست و بدون ساخت متن حذف می‌شود؛ شناسه یا پلتفرم نامعتبرِ پیام متنی همچنان خطاست. سقف پیکربندی‌شدهٔ پیمایش تلگرام پایان یک batch محدود است، با رویداد HISTORY_BATCH_LIMIT_REACHED؛ این رویداد ادعای تکمیل آرشیو ۲۴ساعته ندارد. توقف تاریخچه پیش از سقف، خطاهای استخراج و timeout همچنان partial failure هستند. آزمون فعال‌سازی همچنان حداقل یک خبر و صفر خطای واقعی لازم دارد. شمار پیام، خبر، حذف بدون متن و خطا در گزارش درج می‌شود.

تنها عنوان متنی محدودشدهٔ پروفایل از خروجی اجتماعی عبور می‌کند؛ raw پروفایل و اطلاعات نشست ذخیره نمی‌شوند. در موفقیت آزمون یا دریافت، عنوان استخراج‌شده جای نام خودکار دامنه/آیدی را می‌گیرد؛ نام صریح ادمین حفظ می‌شود. تا دریافت عنوان، آیدی صفحه جای دامنه نمایش داده می‌شود و لینک جدول اجتماعی مسیر صفحه را نشان می‌دهد. دادهٔ موجود بدون اجرای موفق جدید بازنویسی نمی‌شود.

تأیید: تست زنده ۱۰۳ پیام قابل استفاده، صفر خطا، عنوان «جریان» و passed=true؛ آزمون واحد حذف بدون متن و حفظ partial failure و آزمون یکپارچهٔ ذخیرهٔ عنوان/حفظ نام دستی موفق‌اند.
