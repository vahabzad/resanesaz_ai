# ADR-0034 — بازیابی نشانی کامل خبر با شواهد ناشر

تاریخ: 2026-11-02 · وضعیت: پذیرفته‌شده

YJC برای یک شناسهٔ خبری، لینک کوتاه عددی با پاسخ 403 و لینک کاملِ قابل دریافت منتشر می‌کند. برخی لینک‌های کوتاه قدیمی در صفحهٔ اصلی باقی می‌مانند و نشانی کامل فقط در رویداد آزمون موفق قبلی یا sitemap ناشر پیدا می‌شود. بازتولید CSS برای این خطای دریافت، مشکل را حل نمی‌کند.

دریافت مشترک Backend در ساخت، دیباگ و کراول، پس از 403/404 برای مسیر کوتاه عددی خبر، به دنبال نشانی کامل همان شناسه می‌گردد. شواهد مجاز: لینک‌های صفحهٔ منبع، نشانی‌های موفق آزمون قبلی و sitemapهای معرفی‌شده در robots.txt همان origin. نشانی مقصد حدس زده نمی‌شود. تطابق origin، شناسهٔ مسیر، query و نبود credential اجباری است؛ نشانی کامل باید یکتا باشد و canonical و مقصد نهایی صفحه دقیقاً آن را تأیید کنند. ابهام و نبود شاهد همچنان شکست‌اند.

خواندن sitemap محدود به پنج سند، دو فرزند هر index، عمق دو و هزار نشانی است. دریافت‌ها از همان حفاظت HTTPS/DNS/IP/redirect و محدودیت حجم/زمان موجود استفاده می‌کنند. sitemap فقط شاهد حل آدرس است و مجموعهٔ خبرهای کشف‌شده یا معیار تأیید را تغییر نمی‌دهد. عنوان، متن، دسته و حفظ پوشش دیباگ همچنان باید آزمون شوند؛ خطا با حذف نمونه یا شل‌کردن gate مخفی نمی‌شود.

نشانی‌های موفق از رویدادهای آزمون نیز حفظ می‌شوند، چون گزارش نهاییِ یک تلاش ناموفق تمام صفحات موفق تلاش‌های قبلی را در بر نمی‌گیرد. نسخهٔ تأییدشده، نشانی نمونه‌های موفق را برای اجرای بعدی نگه می‌دارد. تمام این داده‌ها Platform-scoped هستند و محتوای سایت همچنان ورودی نامطمئن است. آزمون‌ها، انتخاب یکتا، canonical، سابقهٔ رویداد، sitemap محدود، آدرس خارجی/دارای query و حفظ gate دیباگ را پوشش می‌دهند.
