# قواعد Backend

- Backend مستقل Node.js است و هیچ route یا منطق کسب‌وکاری نباید در Next.js پیاده‌سازی شود.
- `front` فقط از API نسخه‌دار این سرویس استفاده می‌کند.
- منطق استخراج‌شده از پروژه‌های مرجع باید در این Backend بازطراحی و تست شود؛ import یا فراخوانی runtime آن پروژه‌ها ممنوع است.
- Source، Crawler، Crawl Run و Raw Article در Platform Scope هستند. Subscription، Inbox و داده‌های تحریریه در Media Scope و tenant-scoped هستند.
- نقش‌های محصولی جدید سوپر ادمین و ادمین (سردبیر) هستند. مجوزها همچنان در Backend و با deny-by-default اعمال می‌شوند؛ نام نقش محصولی را با مرزهای فنی Platform/Media یکی فرض نکن.
- سوپر ادمین ادمین‌ها را می‌سازد، مجوز منابع هر ادمین را کنترل می‌کند و نگاشت دسته‌بندی منبع به دسته‌بندی داخلی را مدیریت می‌کند. درخواست دسترسی باید actor، منبع/دسته‌ها، وضعیت، تصمیم‌گیر و زمان تصمیم را ثبت کند.
- ادمین می‌تواند چند Media بسازد؛ تنظیم اشتراک منابع و دسته‌بندی فقط در محدودهٔ دسترسی اعطاشده مجاز است. Source و دسته‌بندی خام منبع Platform-scoped می‌مانند و تنظیمات رسانه tenant-scoped هستند.
- worker زیر `back/worker` deployable مستقل است و منطق دامنه را از Backend مصرف می‌کند.
- ورودی شبکه، HTML خبر و خروجی مدل نامطمئن‌اند و باید validation، محدودیت اندازه، SSRF guard و sanitization داشته باشند.
